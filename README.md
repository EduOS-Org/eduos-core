# EduOS

An offline-first, privacy-first, AI-native Linux OS for African schools.

Built for low-spec hardware. No internet required. WAEC/JAMB/NECO curriculum built in.

## Status
Active development — Day 22 of 27 sprint. Target: bootable ISO with working desktop by end of June 2026.

## Architecture
- Compositor: wlroots/tinywl (Wayland)
- Desktop shell: GTK4
- Base: Debian bookworm
- AI tutor: Qwen 2.5 0.5B (offline, quantized)
